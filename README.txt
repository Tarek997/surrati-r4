SURRATI - one design, six sets of type

Open index.html in any browser. Everything is inside this folder:
no internet, no server, no install.

  index.html   the six options, side by side
  a/           Current     Bodoni Moda · EB Garamond · Noto Naskh
  t1/          Roman       Cinzel · Cormorant Garamond · Amiri
  t2/          Couture     Italiana · Tenor Sans · Reem Kufi / Almarai
  t3/          Modernist   Jost · Manrope · Tajawal
  t4/          Apothecary  Fraunces · Spectral · Markazi Text
  t5/          Ruqaa       Prata · Libre Baskerville · Aref Ruqaa / El Messiri

Every one of them is demo A "Cinema", the one you chose - same colours, same
photography, same sections, same measurements. Only the type changes.
a/ is what is live today, kept in the set for comparison.

Each page has EN / AR / MS buttons in the bar at the top. The ARABIC face
changes with the set too, so press the Arabic button before deciding.

b/ and c/ are the other two photography demos from round 4, unchanged.

Prices are placeholders - none of the nine PDFs carries a price.
The order button opens a dialog and sends nothing.
